# Code of Conduct

ReproQuill welcomes contributors of all backgrounds and experience levels.

Be respectful, patient, and constructive. Critique ideas and code without attacking people. Respect privacy, credit others' work, and make room for different perspectives. Help new contributors understand expectations.

Harassment, discriminatory language, threats, unwanted sexual attention, deliberate intimidation, and publishing another person's private information are not acceptable in project spaces or when representing the project.

Maintainers may edit or remove harmful content, limit participation, or ban participants when necessary. They should consider context, explain decisions where safe, and apply these expectations consistently.

For conduct concerns, contact the maintainer through a private contact method listed on [their GitHub profile](https://github.com/Yamiakumi). Do not post sensitive evidence in public issues. If no private contact method is available, ask publicly for one without including identifying details. Reports should be handled with discretion; absolute confidentiality cannot be promised.

This document is the project's own concise conduct policy.
